### Architecture & evidence

This independent Kotlin application uses Jetpack Compose and Material 3. Its Gradle settings include a single `:app` module. Relevant implementation files: `MainActivity.kt`, `Place.kt`.

### Runtime verification

Entered Amsterdam in the search field and verified the filtered city cards. The captured app was rebuilt from a source-fingerprint-checked disposable copy using a separate .portfolio package ID. The existing template JUnit test passed. Android instrumentation tests were not run. Build and capture provenance are recorded in the import manifest.

### Constraints & follow-up

The catalog is bundled with the app, with no location service or remote search.
