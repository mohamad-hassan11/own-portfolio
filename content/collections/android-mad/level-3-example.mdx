### Architecture & evidence

This independent Kotlin application uses Jetpack Compose and Material 3. Its Gradle settings include a single `:app` module. Relevant implementation files: `MainActivity.kt`, `RemindersViewModel.kt`, `AddReminderScreen.kt`, `RemindersListScreen.kt`.

### Runtime verification

Added two fictional reminders through the dedicated form and verified their appearance after returning to the overview. The captured app was rebuilt from a source-fingerprint-checked disposable copy using a separate .portfolio package ID. The existing template JUnit test passed. Android instrumentation tests were not run. Build and capture provenance are recorded in the import manifest.
