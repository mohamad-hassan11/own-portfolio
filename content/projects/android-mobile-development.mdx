## Overview

An intensive, hands-on Android Mobile Development specialisation at the Hogeschool van Amsterdam, progressing from foundational Jetpack Compose concepts to building a complete mobile application independently, alongside applying the same stack professionally during an internship at FacilityApps.

## Context

The university semester combined a smaller Mini Application Development (MAD) project to learn core Compose patterns with a larger end-to-end Android application built solo. In parallel, an internship at FacilityApps applied the same skills to production-facing features.

## Approach

Worked with Kotlin, Jetpack Compose, Android Studio and Gradle (Kotlin DSL), covering composable architecture, state management, navigation, Material Design components and Android testing workflows.

## Results

Delivered a complete solo Android application at university, and contributed Android features professionally at FacilityApps — progressing from UI fundamentals to owning a full feature end to end.

## What I learned

The learning curve moved from UI basics and composable architecture to structuring scalable app modules, handling app lifecycle and state, debugging, and delivering production-style features — strengthening both technical depth in modern Android development and the ability to own a mobile project from idea to implementation.
