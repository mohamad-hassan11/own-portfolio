## Overview

Amsterdam Events is a full-stack web application built during the third semester of my HBO-ICT programme, with an Angular front end and a Spring Boot REST API.

## Approach

Built with Angular 12 (TypeScript, RxJS, Angular Router) on the frontend and Spring Boot (Java 11, REST APIs, Spring Data JPA) on the backend, using H2 for data persistence and JWT for authentication and authorisation.

## Implementation

Designed reusable Angular services and route flows, implemented secure API endpoints, and modelled entities and repositories with Spring Data JPA. Tested the frontend with Jasmine and Karma and the backend with Spring Boot's test tooling.

## What I learned

Grew from building individual UI components to connecting a complete client-server architecture — a strong learning experience in integrating modern frontend development with backend API design, security and database-driven application structure.
