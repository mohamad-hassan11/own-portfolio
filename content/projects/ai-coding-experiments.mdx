<JourneySection id="motivation" title="Learning through building">

I wanted to explore different AI models and CLIs through a working application. Multilingual typing and vocabulary practice gave the builds a shared product goal, with real input, language and interface challenges to work through.

Building two versions created room to try different starting approaches and continue experimenting as features were added.

</JourneySection>

<JourneySection id="approach" title="Different starts, continued experimentation">

KeyLingo’s initial setup used Antigravity with Gemini Flash. LexiType’s initial setup used Codex Sol. After that, I moved between models and coding tools while adding features.

The models I tried included Nemotron, Gemini, DeepSeek, MiMo and Codex. Coding tools included Antigravity, OpenCode and Codex.

I did not retain a feature-by-feature record of which model or CLI did what. The starting setups are the confirmed attribution; later development is presented as a shared exploration.

</JourneySection>

<JourneySection id="keylingo" title="KeyLingo: practice around the keyboard">

KeyLingo combines guided typing practice, reflex drills and vocabulary exercises. Its interface uses a horizontal navigation bar, with a virtual keyboard and finger guidance in practice views.

The source separates typing-session logic, Unicode handling, keyboard mappings and browser persistence from presentation components. English, Dutch and Arabic give that input pipeline different text and layout requirements.

The starting setup used Antigravity and Gemini Flash. The finished application includes later experimentation with other models and coding tools.

</JourneySection>

<JourneySection id="lexitype" title="LexiType: a language practice workspace">

LexiType approaches the same product goal through a sidebar workspace, with learning paths, reflex practice, vocabulary and progress views.

Its source includes locale-prefixed English, Dutch and Arabic routes, a typing engine separated from React, keyboard mappings and recoverable browser data. The portfolio uses the LexiType name to distinguish this implementation.

The starting setup used Codex Sol. Later development involved experimenting with other models and coding tools.

</JourneySection>

<JourneySection id="result" title="Two builds. One exploration.">

The outcome is a pair of multilingual typing and vocabulary applications, developed while moving between AI models and coding tools.

Presented together, KeyLingo and LexiType tell the story behind the similar functionality: repeated building as a way to explore AI coding in practice.

</JourneySection>
