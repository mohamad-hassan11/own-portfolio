## Overview

A big data project that ingests data from APIs, transforms it and presents it as KPI dashboards.

The application is built with Python, Flask and Dash / Plotly on top of SQLAlchemy and MySQL. It is tested with Pytest and delivered with Docker, Terraform and a CI/CD pipeline.
