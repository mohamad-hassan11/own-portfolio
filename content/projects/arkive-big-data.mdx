<JourneySection id="overview" title="Overview">

A production-oriented analytics platform built for Arkive during the Big Data minor at the Hogeschool van Amsterdam: ingesting data from external APIs, transforming it, and presenting it as KPI dashboards.

</JourneySection>

<JourneySection id="context" title="Context">

The Big Data minor combined a solo onboarding assignment with this company-based team project at Arkive, supported by workshops on data engineering, cloud deployment and collaborative development practices.

</JourneySection>

<JourneySection id="approach" title="Approach">

Built API-based data ingestion and transformation pipelines feeding a MySQL database through SQLAlchemy, then exposed the results through Flask with Dash / Plotly dashboards for KPI visualisation.

</JourneySection>

<JourneySection id="design" title="Design">

The interface was mocked up before it was built: a login screen and a dashboard of six KPI cards.

The dashboard mockup defines six KPIs:

- Return on inventory cost (gross)
- Conversion rate
- Sell-through rate
- Revenue per SKU
- Days of inventory on hand
- Return rate

</JourneySection>

<JourneySection id="dashboards" title="Dashboards">

The implemented application follows the mockups. Access starts at a login screen, and accounts are created by an admin.

The KPI dashboard is filtered by product and by a month range, and its data can be exported to Excel.

A separate statistics page gives vendor-level views of the catalogue and inventory.

</JourneySection>

<JourneySection id="implementation" title="Implementation">

Automated the pipeline and dashboard behaviour with Pytest, and packaged deployment with Docker, Terraform and shell scripts inside a CI/CD workflow.

</JourneySection>

<JourneySection id="what-i-learned" title="What I learned">

Moved from building standalone analyses to delivering a maintainable, team-based data application under real-world constraints: data quality, database design, dashboard UX, version-control workflow, testing and cloud-ready deployment.

</JourneySection>

</ProjectJourney>
