## Overview

Graduation project at DEVENTit: natural-language search for an enterprise application, built on retrieval-augmented generation (RAG).

Retrieval combines dense vector embeddings for semantic matching with BM25 for keyword matching, and security and role-based access control are treated as core requirements rather than an afterthought.

## Focus areas

- Natural-language search over enterprise data
- Hybrid retrieval: dense vectors plus BM25
- Security and role-based access control
- Python and FastAPI service backed by a vector database and LLM APIs
