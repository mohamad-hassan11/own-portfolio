## Overview

PAD is a full-stack web application built during the second semester of my HBO-ICT programme, with a Node.js and Express backend and a modular vanilla frontend.

## Approach

Built with Node.js and Express on the backend, MySQL for data storage, and a modular frontend using HTML, CSS, JavaScript (ES6) and Bootstrap. The architecture follows an MVC-style pattern with a clear separation between views, controllers and repositories, plus API communication through AJAX and session handling in the browser.

## Implementation

Implemented REST-style endpoints, asynchronous client-server communication, and end-to-end tests with Cypress.

## What I learned

Strengthened client-server design, REST-style API development, asynchronous programming, database integration and end-to-end testing, while learning how to structure and maintain a team-scale codebase from both frontend and backend perspectives.
