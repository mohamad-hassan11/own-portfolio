## Overview

FlyFriends is a team-built web application from the first semester of my HBO-ICT programme, where travellers can create profiles, select interests and find matching travel partners.

## Approach

Built with HTML, CSS and JavaScript in a modular multi-page setup, using the FYSCloud platform for API/database access, session handling and client-side route protection.

## Implementation

Worked with SQL-style queries, dynamic DOM rendering, filtering logic and asynchronous data flows to deliver login, profile management, matching and friend requests.

## What I learned

The biggest learning curve was moving from basic frontend pages to a full-stack mindset: structuring maintainable page-specific scripts, handling real user state, writing reliable database queries from the client layer, and coordinating team development across multiple connected features.
