## Overview

Festivals is a native Android application engineered as the capstone project for the HBO-ICT Android Mobile Development specialisation semester at the Hogeschool van Amsterdam (HvA). The application serves as a comprehensive festival companion, bringing event discovery, dynamic artist lineup inspection, ticket reservation workflows, personal packing checklists, and cashless wristband balance monitoring together into a single mobile experience.

Built with Kotlin and modern Android Jetpack libraries, the application demonstrates a fully declarative UI with Jetpack Compose and Material 3, a robust local-first relational database powered by Room ORM with many-to-many entity joins, and a cloud-backed authentication and profile layer using Firebase Firestore.

## The problem and constraints

Outdoor music and dance festival attendees typically navigate disjointed channels: third-party ticketing platforms, separate festival schedule apps, physical payment wristbands, and unorganized notes for festival prep. Mobile web apps and hybrid wrappers frequently suffer from poor responsiveness, high memory overhead, and clumsy offline resilience in festival environments with weak cellular coverage.

The engineering challenge was to build an end-to-end native Android application satisfying strict technical constraints across UI, local persistence, cloud boundaries, and defensive state verification:

## Result & architectural post-mortem

The Capstone Festivals project delivered a complete, polished native Android application that successfully demonstrates modern Android engineering practices: completely declarative UI in Jetpack Compose with Material 3 styling and dynamic light/dark theming, robust multi-table SQLite relational persistence using Room ORM with many-to-many junction entities, clean MVVM separation with Android ViewModels, Coroutines, and LiveData state streams, and cloud integration with Firebase Firestore.
